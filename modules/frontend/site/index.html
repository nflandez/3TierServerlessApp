    How this page works

    1. Presentation: these files come from a private S3 bucket through CloudFront over HTTPS.
    2. Authentication: sign-in happens on the Cognito hosted page, which returns a token to this page.
    3. Application: the page sends the token to API Gateway, which checks it and invokes Lambda.
    4. Data: Lambda reads and writes your tasks in DynamoDB.
